# Crypto Live — цены криптовалют в реальном времени (Android)

**Скачать:** https://superpayilmir-crypto.github.io/CryptoLive/

Живые цены с бирж **Binance / Bybit / OKX** через WebSocket (обновление каждую секунду и чаще).

* Любые монеты: вводите тикер (`SOL`, `PEPE`, `ETH/BTC`, `TONUSDC`) — приложение проверит, что пара торгуется на выбранной бирже.
* **Живые обои** на экран блокировки и рабочий стол: фото Мальдив с плавной анимацией, чёткие цены, плашки изменения и спокойный график за 24 часа. Темы: Мальдивы, Пляж, Океан, Космос, AMOLED.
* **Уведомление с ценами** — видно на заблокированном экране на любом телефоне (включая Xiaomi/HyperOS).
* Когда экран выключен — соединение на паузе, батарея не тратится.
* Android 8.0 и новее.

## Как получить APK (способ 1 — без установки программ, через GitHub)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите **New repository** → имя `CryptoLive` → **Create repository**.
3. На странице репозитория: **uploading an existing file** → перетащите **всё содержимое** распакованной папки `CryptoLive`
   (важно, чтобы загрузилась и папка `.github` — на Mac/Windows включите показ скрытых файлов) → **Commit changes**.
4. Откройте вкладку **Actions** → сборка «Build APK» запустится сама (≈3–5 минут).
5. Когда появится зелёная галочка — откройте сборку, внизу в **Artifacts** скачайте `CryptoLive-apk`, распакуйте, перекиньте `app-release.apk` на телефон и установите (разрешите «установку из неизвестных источников»).

## Способ 2 — Android Studio

Откройте папку `CryptoLive` в Android Studio → дождитесь синхронизации → **Build → Build APK(s)** или сразу ▶ Run на подключённом телефоне.

## Как поставить на экран блокировки

1. В приложении добавьте нужные монеты и выберите биржу.
2. Нажмите **«Установить живые обои»** → **Установить** → **«Главный экран и экран блокировки»**.
3. Если телефон не ставит сторонние живые обои на экран блокировки (часто Xiaomi/Redmi/POCO), включите переключатель **«Уведомление с ценами»** — цены будут на заблокированном экране в виде уведомления.
   На Xiaomi дополнительно: Настройки → Приложения → Crypto Live → Автозапуск ✓ и Контроль активности → «Нет ограничений».

## Если нет данных

Некоторые биржи недоступны в отдельных странах/у операторов. Просто переключите биржу в приложении (Binance ↔ Bybit ↔ OKX).
